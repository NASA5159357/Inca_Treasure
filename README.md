## 项目简介

`Inca_Treasure` 是一款基于 **Vue 3** 开发的游戏线上版本。在这里，玩家将扮演一位勇敢的探险家，深入秘鲁的安第斯山脉，探索古老的印加文明遗址，解开重重谜题，寻找传说中遗失的黄金城。

## 核心特性

- **沉浸式体验**：精心设计的游戏场景与音效，带你瞬间穿越至神秘的古印加。
- **极致性能**：采用 Vue 3 组合式 API (Composition API) 结合 Vite，确保游戏流畅运行，极速加载。
- **趣味关卡**：结合历史与解谜，每一关都是对智慧与勇气的挑战。
- **多端适配**：完美兼容桌面端与移动端，随时随地开启寻宝之旅。

## 技术栈

| 技术 | 说明 |
| :--- | :--- |
| **Vue 3** | 核心框架，高效构建响应式 UI |
| **Vite** | 极速前端构建工具 |
| **TypeScript** | 强类型保证代码质量 |
| **Pinia** | 状态管理，轻松处理复杂的逻辑流 |
| **UnoCSS** | 原子化 CSS，极简样式方案 |
| **Canvas / WebGL** | 渲染核心，实现高性能游戏画面 |

## 快速启动

> [!NOTE]
> 项目目前处于初期开发阶段，更多精彩功能敬请期待！

在开始之前，请确保你的环境中已安装 [Node.js](https://nodejs.org/) (建议版本 v18.0.0+)。

```bash
# 1. 克隆仓库
git clone https://github.com/NASA5159357/Inca_Treasure.git

# 2. 进入目录
cd Inca_Treasure

# 3. 安装依赖
npm install # 或者 pnpm install / yarn

# 4. 运行开发服务器
npm run dev
```
